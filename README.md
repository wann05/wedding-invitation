# Digital Wedding Invitation

A digital wedding invitation website built with HTML, CSS, Bootstrap, and JavaScript. This project provides an elegant and responsive way to share wedding information online.

## About the Project

Digital Wedding Invitation is a website designed to present wedding details in a simple and interactive format. Guests can access the invitation online to view event information, explore wedding photos, and find other important details about the celebration.

## Built With

* HTML5
* CSS3
* Bootstrap 5.3.8
* JavaScript

## Features

* Responsive design for desktop and mobile devices.
* Wedding event details and schedule.
* Photo gallery.
* Background music.
* Elegant and interactive invitation layout.

## Live Demo

Visit the website: https://wedding-invitation-dig.netlify.app/

## Getting Started

1. Clone this repository.

   ```bash
   git clone https://github.com/wann05/wedding-invitation.git
   ```

2. Open the project folder.

   ```bash
   cd wedding-invitation
   ```

3. Open `index.html` in your browser to view the website locally.
